# I Am Lead — Document Templates

Все шаблоны bilingual: русское название раздела сопровождается английским.

## Правила использования / Usage rules

- Заполняйте конкретными фактами, цифрами и ссылками.
- Не заполняйте разделы формально: если раздел не применим, объясните почему.
- Используйте статус документа и владельца.
- Русская версия помогает обучению; английские термины сохраняются для переноса навыка в международную среду.
